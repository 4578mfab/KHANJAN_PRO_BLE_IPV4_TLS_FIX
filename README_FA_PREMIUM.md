# خانجان — نسخه رابط کاربری براق

این پروژه کامل Flutter برای بارگذاری در یک مخزن جدید GitHub آماده شده است.

- نوار پایین سه‌گزینه‌ای: خانه، تنظیمات، ظاهر
- ۱۲ تم پررنگ با رنگ‌های زنده
- ۲۰ رنگ براق مستقل برای کلیدها
- کارت‌های دارای گرادیان و درخشش هنگام روشن بودن
- انتخاب آیکون برای هر کلید: لامپ، پنکه، قفل، در، گاراژ، دوربین و موارد دیگر
- امکان افزودن کلیدهای بیشتر حفظ شده است
- تنظیمات قبلی بدون آیکون نیز با آیکون پیش‌فرض بارگذاری می‌شوند
- فایل‌های MQTT و workflow ساخت APK از پروژه اصلی حفظ شده‌اند

## ساخت APK
تمام محتویات ZIP را در ریشه مخزن جدید GitHub قرار بده. سپس از زبانه Actions اجرای workflow ساخت APK را بررسی کن و APK را از بخش Artifacts دانلود کن.


## قابلیت چندداشبوردی (نسخه جدید)
- پس از صفحه لوگو، صفحه انتخاب داشبورد نمایش داده می‌شود.
- داشبورد اصلی با تنظیمات قبلی برنامه حفظ می‌شود.
- از بخش «تنظیمات» > «مدیریت و افزودن داشبورد» می‌توان داشبورد جدید ساخت، نام آن را تغییر داد یا حذف کرد.
- تنظیمات MQTT، موضوع دما، موضوع وضعیت ESP32 و کلیدها برای هر داشبورد جداگانه ذخیره می‌شوند.
- داشبورد جدید با تنظیمات فعلی کپی می‌شود تا بتوانید از تنظیمات همان‌جا شروع کنید؛ برای ESP32 جدید، موضوع‌های MQTT را در تنظیمات داشبورد تازه ویرایش کنید.
- برای برگشت به فهرست داشبوردها، از صفحه کلیدها دکمه بازگشت گوشی را بزنید.

**نکته:** در این محیط ابزار Flutter نصب نیست؛ بنابراین سورس را بررسی و بسته‌بندی کرده‌ام، اما APK را اینجا کامپایل نکرده‌ام. فایل APK را با workflow موجود GitHub Actions بسازید.


## اصلاحات چندداشبوردی و وضعیت زنده

- کارت‌های فهرست داشبورد دیگر تعداد کلید ثابت/نمایشی ندارند و نام داشبورد در کارت وضعیت نمایش داده می‌شود.
- کارت دما دارای گیج نیم‌دایره‌ای عقربه‌دار با بازه ۲۰ تا ۵۰ درجه است؛ اگر پیام دمای تازه نرسد، `?` نمایش داده می‌شود.
- پیام‌های retained قدیمی وضعیت و دما برای جلوگیری از نمایش داده کهنه نادیده گرفته می‌شوند.
- برای وضعیت آنلاین دقیق، فایل `firmware/SmartControl_6LED_StatusFix.ino` نیز ارسال وضعیت زنده را هر ۱۵ ثانیه انجام می‌دهد. پیش از آپلود، مقادیر `YOUR_WIFI_SSID` و `YOUR_WIFI_PASSWORD` را با اطلاعات Wi-Fi خودتان جایگزین کنید.
- نسخه برنامه به `1.0.1+2` افزایش یافته تا APK جدید امکان نصب به‌روزرسانی روی نسخه قبلی را داشته باشد.

**مهم:** سورس Flutter در این محیط کامپایل نشده است. قبل از نصب روی گوشی، پروژه را با GitHub Actions بسازید و ابتدا APK جدید را آزمایش کنید.
